🛠️ Panduan Edit & Deploy ke Vercel:

1. Ganti Foto di VS Code: Cari tag <img src="..."> di dalam file index.html ini. Ganti link gambar Unsplash dengan link foto Vania / foto kamu sendiri.

2. Ganti Lagu: Link lagu saat ini memakai MP3 Indecision - Rex Orange County.

3. Push ke GitHub: Buat repository baru di GitHub, upload file index.html ini.

4. Deploy Gratis di Vercel: Login ke Vercel.com -> Klik "Add New Project" -> Pilih repo tadi -> Klik "Deploy". Kirim link web cantik ini ke Vania! 🎉
